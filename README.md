# Studentgithub

학생들이 바이브코딩으로 만든 과학 시뮬레이터를 모아 서로 돌려 보고 평가하는 전시관입니다.

- 주소: https://scienceisjo.github.io/studentgithub/
- 학번과 별명으로 들어가면 하던 단계부터 이어집니다(작업실 7단계: 고치기 기록 · 모형 생각 · 만들기 · 점검표 · 자기평가·성찰 · 제출 · 서로 평가).
- 올린 앱은 선생님 확인 뒤 전시관에 나오고, 샌드박스 안에서만 실행되어 사이트와 기록에 손을 대지 못합니다.
- `?local=1` 을 붙이면 서버 없이 이 기기에서 체험할 수 있습니다.
- 첫 과제: 기체의 성질 「나만의 공기 시뮬레이터」 (`starter/gas.html` = 검증된 시작 앱)

서버 준비물(SQL)은 이 저장소에 두지 않습니다.
